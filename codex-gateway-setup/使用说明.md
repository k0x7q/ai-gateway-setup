# Codex 网关配置

推荐使用[项目首页](<../README.md>)中的在线启动命令。工具仅配置网关，不安装 Codex 客户端。

## 离线运行

完整解压对应系统的压缩包，保持启动文件和“辅助文件”文件夹在一起。网关地址通过 `AI_GATEWAY_URL` 传入；直接双击且未提供该环境变量时会停止。

macOS 终端：

```bash
AI_GATEWAY_URL='https://gateway.example.com' /bin/bash './mac/双击此文件配置 Codex.command'
```

Windows PowerShell：

```powershell
$env:AI_GATEWAY_URL = 'https://gateway.example.com'
& './windows/双击此文件配置 Codex.cmd'
```

将示例地址替换为实际 HTTPS 网关域名或 IPv4 地址，可带端口及末尾 `/`，不可包含其他路径、账号、查询参数或片段。工具自动追加 `/v1`，无需手动添加。不要将实际地址或 API Key 提交到公开仓库。

## 操作流程

1. 已有同一网关的密钥时，选择复用或输入新密钥；否则直接输入。输入内容为明文。
2. 如果 Codex 正在运行，保存工作并自行退出后重试。本工具不会强制关闭应用。
3. 自动保存配置并验证网关，验证成功且检测到应用时请求打开 Codex。

失败诊断说明阶段、原因和配置保存状态。网络验证失败时配置可能已经保存，不要直接删除或清空原配置。配置期间不要提前关闭启动窗口；系统安全提示仍可能出现，请确认文件来源后操作。

已有配置在修改前备份。输入框、配置及备份中的密钥都是明文，请勿分享。
