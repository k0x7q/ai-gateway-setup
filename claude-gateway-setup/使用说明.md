# Claude Code 安装配置（维护说明，不随包分发）

推荐使用[项目首页](<../README.md>)中的在线启动命令。网关地址由命令传入，不内置在工具中。

本目录也保留离线入口；完整解压后，启动文件和“辅助文件”文件夹必须放在一起。离线运行需先提供 `AI_GATEWAY_URL`，直接双击且未配置该环境变量时会停止。以下使用示例地址，运行前替换为实际网关域名。

macOS 终端：

```bash
AI_GATEWAY_URL='https://gateway.example.com' /bin/bash './mac/双击此文件安装配置 Claude Code.command'
```

Windows PowerShell：

```powershell
$env:AI_GATEWAY_URL = 'https://gateway.example.com'
& './windows/双击此文件安装配置 Claude Code.cmd'
```

网关地址只支持 HTTPS 域名或 IPv4 地址，可带端口及末尾 `/`，不可包含其他路径、账号、查询参数或片段。不要将实际地址或 API Key 提交到公开仓库。

## 正常流程

1. 检查辅助文件完整性、配置路径、编码与 JSON 结构。配置异常时先报告，不先安装一轮软件。
2. 每次都显示密钥相关窗口。已有同一网关密钥时选择“使用现有密钥”“输入新密钥”或“取消”，不显示已有密钥；否则直接输入。
3. 新密钥输入为明文，提示只保留“请输入网关密钥”。无效输入保持可重试。取消密钥选择正常结束，不安装或修改配置。
4. 检查所需软件，已有可运行版本就复用；确实缺失时显示一次按需安装确认。取消这一步不会开始安装。
5. 保留官方 HTTPS 下载、安装包校验和必要系统授权。Mac 的 Node.js pkg 可能要求管理员授权；Windows 的 Node.js/Git 安装可能出现系统 UAC。不要以管理员身份运行整个配置入口，也不要使用 sudo npm。
6. 用私有标准输入管道把选定密钥交给共享配置器，再次验证原文件摘要，备份并安全合并配置，完成命令路径配置。
7. 成功保留简短保存状态与下一步：在项目目录打开新终端，运行 `claude`。Windows 终端在流程结束后显示“按任意键关闭此窗口”，等待用户查看结果后再关闭；Mac 在交互终端启动时清理当前屏幕的登录和命令回显，结束后显示“流程已结束，可以关闭此终端窗口”，保持结果直到手动关闭窗口；按回车不会退出，Ctrl+D 可主动结束。必要警告和错误诊断保留，不清除滚动历史，不修改终端全局设置或 shell 历史记录。非交互运行不清屏、不等待，保留原退出码。不自动打开项目或启动 Claude Code。

本工具不发送模型请求，也不验证网关密钥或模型是否可用。遇到其他认证、模型或云平台环境设置时保留必要警告，不静默删除个人设置。

## 错误与取消

失败窗口提供“复制诊断信息”和“关闭”。诊断包含编号、阶段、具体脱敏原因、可确定的 JSON 行列、工具退出码，以及软件安装、配置保存、PATH 的独立状态。系统窗口打不开时在终端显示同样诊断；Windows 无论成功、失败还是取消，都保留终端结果直到用户按键，缺少 PowerShell 时也一样。

不要把失败解释为已经回滚：软件可能已安装，配置可能已保存，PATH 也可能部分完成。配置子进程中断或返回非法协议时明确标记保存状态未知。密钥取消属于正常退出，不追加故障提示。

API Key、配置与备份可能包含明文凭据，不要发送给他人。新输入可见不意味着诊断、命令参数、环境变量或临时文件允许泄露密钥。

## 安装渠道与系统限制

保持现有渠道：Node.js 官网最新 LTS、npm 官方仓库的 `@anthropic-ai/claude-code`，Windows 缺 Git Bash 时按现有官方 Git 安装流程处理。Mac 首次打开下载的 `.command` 仍可能需要系统安全放行，不关闭安全保护，也不自动移除 quarantine。
